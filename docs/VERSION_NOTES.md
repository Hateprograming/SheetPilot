# SheetPilot Agent v2.1.0

## UAT 标准化、转换与公式修复

聊天中的泛化“标准化”默认按 NFKC、去首尾空白的顺序执行，保留前导零、内部空格和数值类型；明确要求仅做某项操作时遵从该规则。覆盖原列仍需在计划中确认。

XLSX 转 CSV 的主下载、本次结果和历史版本下载均交付对应版本的 CSV，默认 UTF-8 BOM。内部 XLSX 继续用于预览与后续处理；多工作表未指定来源时先选择工作表。CSV 可以作为复合计划的最后一步。

公式支持明确的列名运算，例如“在总额列填入数量×单价”或“总额=数量*单价”，支持加减乘除、括号及常量，不要求用户手写单元格引用。非空目标默认保留。公式写入和计算缓存均通过核验后才提交正式结果；缺少引擎、重算超时或计算错误会暂停，可从检查点重试。

Windows 优先使用本机 Excel，其他环境使用 LibreOffice；Docker 镜像包含 LibreOffice Calc，需要重新构建镜像生效。两个引擎共享最多 90 秒重算预算，并受任务剩余预算约束。停止处理会终止本次启动的重算进程。

回归用例位于 `tests/test_uat_regressions.py`。真实引擎集成测试需安装 Excel 或 LibreOffice，并设置 `SHEETPILOT_EXCEL_INTEGRATION=1` 后运行 `tests/test_excel_recalculation.py`，覆盖 3,000、5,000、40,000 行的写入、重算与核验。

本次更新提升了标准化、公式、转换的能力版本。部署后涉及这些能力的旧计划需要重新生成并确认，已有正式文件版本仍可下载和恢复。

## P0 网页闭环补强（2026-10-17）

网页端新增本次操作与正式结果版本绑定、业务核验摘要、异常类型分页及原始 Excel 行定位、阶段耗时与可修改反馈。净省时仅使用用户提供的两次完整耗时计算，缺失数据不补估。

默认只向配置的模型发送用户任务文字、文件结构及统计；异常目标值需另行授权，授权绑定操作、版本和具体内容。上传时展示接收方和模型，不自动勾选同意。完整文件、完整行及自动拼接的历史助手文本不作为默认模型上下文。

任务闲置7天清理，可主动删除；轮询不续期。FastAPI 在启动时和每小时扫描，运行中任务跳过，删除失败停止访问并重试。执行默认600秒预算，到安全步骤边界暂停；规划默认180秒预算，迟到响应不发布。旧 Streamlit 保持兼容，网页是本轮新增体验的主要入口。

新增接口包括数据说明、按操作反馈、异常分页及按请求数据授权；全部工作簿接口继续校验会话所有权。部署参数、管理员只读统计导出及待完成的真实用户测试见 `../Guidance/P0Acceptance.md`。本轮没有增加制表或任意代码执行能力。

SheetPilot 是一个聊天驱动的本地表格 Agent。v2.0 在声明式 Skill Harness、事务执行和版本恢复基础上，新增可审计的数值填补、分类映射、尺寸解析和受控派生指标。v2.0.1 加入即时消息回显、后台规划、可中断执行、状态时间线和脱敏异常行预览；v2.0.2 让澄清回答能够续写同一计划草案，并支持按 Excel 行号修正尺寸异常；v2.0.3 修复混合类型预览，支持显式去后缀数值化、映射默认值以及“长宽高或直径³”的组合体积规则；v2.0.4 修复换行表头解析和无效列预检，并严格保证每个 Transform 步骤只包含一种操作；v2.0.5 修复复合计划澄清循环、未经授权的模型默认值和 one-hot 规则漂移；v2.0.6 将结果预览改为单次顺序读取，解决宽表预览长时间卡住的问题，并在预览中区分重复表头；v2.0.7 防止将多个 one-hot 要求合并为单列，改进带文字备注的尺寸提取和部分尺寸上下文校验，并让重复数值异常通过脱敏行预览进入可续写的澄清闭环；v2.0.8 新增受控列保留/删除能力，并可从上一轮结果的列血缘恢复“我提到的列和你生成的列”，修复工作表澄清循环；v2.0.9 在澄清问题中明确受影响列与具体异常，修复异常原始值对象的界面展示，并可精准删除仅用于记录 `mapped`/`mapped_default` 的 Indicator 状态列；v2.0.10 将分类映射状态改为内部审计信息，默认只输出 Indicator 数值列，只有用户明确要求时才在工作簿中创建映射状态列。整体计划经用户确认后，每一步在内部检查点上执行并核验，全部通过后才提交一个新的正式文件版本。

## Web UI

新的 React + FastAPI 网页工作区位于 `web/`，覆盖上传、结构理解、澄清、计划确认、执行、核验和版本恢复。每个浏览器使用独立的匿名会话，任务所有权在服务端逐请求校验；网页数据默认保存在独立的 `data_web/`，不会读取旧 Streamlit 工作区。

开发启动：

```powershell
cd web
npm install
npm run build
cd ..
.\.venv\Scripts\python.exe -m uvicorn sheetpilot.web_api:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。修改前端时可另开终端运行 `npm run dev`，Vite 会把 `/api` 代理到 8000 端口。

Docker 部署前请在 `.env` 设置真实的 `SHEETPILOT_SESSION_SECRET` 和模型配置，然后运行：

```powershell
docker compose up --build
```

首版部署必须保持单实例、单 worker；当前 SQLite、进程内任务执行器和本地版本文件不支持多实例横向扩容。


## 使用流程

1. 上传一个 `.xlsx` 工作簿或 `.csv` 文件并完成本地结构分析；
2. 在聊天框中描述期望结果，不需要选择任务类型或填写工具参数；
3. 回答 Agent 提出的关键澄清问题，或直接确认中文执行计划；
4. Agent 在工作副本上执行并核验；
5. 在对话中预览结果、下载文件，或继续提出下一项修改。

计划修改同样通过自然语言完成，例如“来源表改成客户主数据”“重复编号使用最后一条”。结构化参数仅在计划卡的技术详情中用于审计，不作为普通用户操作入口。

## v2.0 Skill Harness

- 八个版本化 Skill：保留 v1.0 的匹配、标准化、聚合、排序排名、清洗、公式和文件转换，新增 Transform；
- Agent 只能在 Skill 能力契约内规划，不能发明工具或降低规则风险；
- 复合任务会验证 Skill 兼容性、步骤依赖和中间结构；
- 不支持的请求返回边界原因、替代方案和可继续使用的表达；
- CSV 转 XLSX 默认保留文本；XLSX 可将指定 Sheet 导出为 UTF-8 BOM CSV；
- 上传的 CSV 在显式转为 XLSX 的计划获批前不能进入其他 Skill；XLSX 导出 CSV 可作为复合计划最后一步。

## v0.3 延续能力

- 复合任务：标准化、匹配、聚合、排序和清洗可组成 2–5 步依赖计划；
- 事务执行：中间结果不作为正式版本交付，最终只提交一个新版本；
- 持久化恢复：步骤、尝试次数、输入输出哈希和检查点写入 SQLite；
- 保守重试：瞬时 I/O 错误使用原参数自动重试一次，其他错误暂停；
- 计划修订：修订号变化后旧审批自动失效；
- 公式诊断：检测断层、`#REF!` 和模式异常，在候选唯一时填补或替换；
- 公式支持诊断、断层修复、异常替换、显式设置、样板复制和整簿重算。
- Windows 优先调用本机 Microsoft Excel 完整重算并写回缓存值；其他环境回退到 LibreOffice。
- 若没有可用计算引擎，保留未提交工作副本与检查点，暂停计算任务；安装引擎后可重试。用户明确要求只检查公式文本时可跳过重算。

### 公式能力边界

| 模式 | 行为 | 风险 |
|---|---|---|
| `diagnose` | 读取公式，识别断层、`#REF!` 和模式异常，并刷新计算缓存 | 低 |
| `fill_gaps` | 仅在上下公式平移后得到同一候选时填补空白 | 中 |
| `replace_outliers` | 替换可唯一推断的已有异常公式 | 高 |
| `set_formula` | 使用用户明确提供的公式或列名算式，并按相对引用填入目标范围 | 中；覆盖时为高 |
| `copy_formula` | 从指定样板行平移复制公式，默认不覆盖非空单元格 | 中；覆盖时为高 |
| `recalculate` | 不改公式文本，只刷新整份工作簿的公式缓存和错误状态 | 低 |

Agent 不会自行发明业务公式。`set_formula` 必须由用户提供公式文本；结构正确且可计算也不代表业务含义正确。

## 支持范围

1. 跨 Sheet 精确匹配
   - 同一工作簿、两个 Sheet、单列键、左连接、追加 1–3 列静态值；
   - 精确文本或显式数值等价；
   - 重复来源键可阻止、保留第一条或最后一条；
   - 空键和未匹配记录写入异常 Sheet。

2. 数据标准化
   - Unicode NFKC、去除首尾空格、大小写统一；
   - 转文本、转数值、明确格式的日期转换、常量填充空值；
   - 默认写入新列，覆盖原列会标记为高风险。

3. 聚合与汇总
   - 1–3 个分组列；
   - 求和、计数、平均、最小值和最大值；
   - 最多 5 个结构化筛选条件；
   - 结果写入新 Sheet。

4. 排序、排名与 Top N
   - 最多 3 个排序列；
   - 全表或分组排名；
   - 密集排名、竞赛排名和并列末位策略；
   - 结果写入新 Sheet。

5. 基础清洗
   - 按 1–5 列精确识别重复；
   - 标记重复或保留第一/最后一条；
   - 按结构化条件筛选；
   - 结果写入新 Sheet。

6. 文件转换
   - CSV 转 XLSX，支持 UTF-8、UTF-8 BOM、GB18030 和常见分隔符；
   - 默认保留前导零、长编号和日期文本，仅在用户明确要求时推断类型；
   - 将 XLSX 中指定 Sheet 导出为 UTF-8 BOM CSV。

7. 可审计数据准备
   - 重复表头、空表头和无数据模板列使用稳定列引用处理；
   - 数值均值/中位数/常量填补；格式错误默认不当作缺失，用户明确授权后可使用同一统计量二次填补；
   - 多列显式值映射，固定执行 trim + NFKC，可选 casefold；
   - 尺寸解析输出长、宽、高、最大径和逐行状态；支持经用户确认的多候选取值、混合单位逐项换算、异常置零和精确文本修正；
   - 体积仅允许用户明确选择的椭球、半乘积或长方体公式，并将 mm³ 换算为 cm³；
   - 同类无效派生输入重复出现时提供统一处理选项；结果默认留空，只有用户明确授权后才可置 0；
   - 异常行默认留空、写状态并生成不含额外患者标识列的 UTF-8 BOM CSV；同类异常重复出现时，以 2～3 个选项询问统一处理规则，同时保留自然语言输入；
   - 覆盖原列需要额外确认；已有派生列依赖来源时，必须在新计划中一并重算。

## 安全边界

- 仅 `.xlsx`，默认最大 20 MB、单 Sheet 最大 100,000 行；
- 不处理宏、Power Query、外部链接、密码保护或复杂合并表头；
- 不支持模糊匹配、联合键、一对多展开、多工作簿或任意代码执行；
- 单任务最多五个业务步骤，不允许嵌套复合计划；
- 公式业务含义仍需用户确认；系统可验证公式结构、计算缓存和 Excel 错误，但无法证明业务公式本身符合真实业务规则；
- 执行前重新检查输入版本，防止旧计划作用于新文件；
- 每个工具执行 `validate → preview → approval → checkpoint → execute → verify`；
- 核验失败时删除失败输出，不提交为文件版本。

## 恢复语义

- 工具步骤执行期间不可中断，暂停和取消在步骤边界生效；
- 已完成步骤的检查点可供失败恢复，应用重启后仍可继续；
- 完成后删除中间工作簿，保留运行记录、哈希和核验报告；
- 取消、严重错误或最终核验失败都不会改变上一正式版本。
