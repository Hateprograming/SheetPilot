# SheetPilot

**用自然语言处理 Excel，让表格操作从“找功能、写公式”变成“说清楚想要什么”。**

[在线体验 SheetPilot](https://sheetpilot-3pin.onrender.com/)

SheetPilot 是一个对话式表格处理工具。你可以上传 Excel 或 CSV 文件，直接描述想完成的工作；SheetPilot 会先理解文件结构和你的要求，给出可确认的操作计划，再执行处理并生成可下载的新文件。

它适合规则明确、但手工操作繁琐的表格任务，例如数据清洗、跨表匹配、汇总排名、公式填充和格式转换。

> 这是一个产品项目与在线演示版本，目前适合使用示例数据或脱敏数据进行体验。

## 可以用它做什么

| 场景 | 你可以这样说 |
| --- | --- |
| 跨表匹配 | “按客户编号匹配客户表，给订单表补充客户等级和地区。”目前支持同一工作簿内两个工作表的单列键精确匹配。 |
| 数据清洗 | “去掉手机号列两端的空格，并标记重复记录。” |
| 内容标准化 | “统一省份名称的大小写和空格，保留编号前面的 0。” |
| 汇总统计 | “按部门汇总销售额，计算总额和平均值。” |
| 排序与排名 | “按销售额从高到低排序，并生成部门内排名。” |
| 数据填补与映射 | “用中位数填补年龄列的空值，把性别映射成 0 和 1。” |
| 公式处理 | “在总额列填入数量 × 单价，并检查是否存在公式断层。” |
| 文件转换 | “把 CSV 转成 Excel。”或“把这个工作表导出为 CSV。” |

SheetPilot 会在执行前把理解到的规则写成计划。识别到重复编号、多个可能的工作表、覆盖已有内容或异常值等歧义时，它会优先向你确认；执行前仍请核对计划是否符合预期。

## 怎么使用

1. 打开 [SheetPilot 在线体验](https://sheetpilot-3pin.onrender.com/)。如果服务一段时间没有被访问，首次打开可能需要稍等片刻。
2. 上传一个 `.xlsx` 或 `.csv` 文件。建议第一次使用小型示例文件。
3. 在对话框中描述目标。尽量说明要处理的工作表、列名和希望得到的结果。
4. 根据提示补充缺失的规则，例如重复数据保留哪一条、结果写入新列还是原列。
5. 阅读 SheetPilot 生成的操作计划，确认无误后开始执行。
6. 查看处理摘要和结果预览，确认后下载新文件。原始上传文件不会被直接覆盖。

如果结果还需要调整，可以继续在同一个对话中提出要求，例如：

> 来源表改成“客户主数据”，重复客户编号保留最后一条。

## 怎样描述需求更容易得到正确结果

一个清晰的请求通常包含三部分：**处理哪个位置、使用什么规则、结果放在哪里**。

例如：

> 在“订单”工作表中，按“客户编号”匹配“客户”工作表的同名列，把“客户等级”和“地区”追加到订单表。重复客户编号保留第一条。

你不需要编写单元格引用、程序代码或工具参数。对于公式任务，可以直接使用列名描述，例如“总额 = 数量 × 单价”。

如果需求包含多个步骤，也可以一次说明：

> 先去掉商品编号两端的空格，再按商品编号汇总销售额，最后按销售额从高到低排序。

## 在线体验限制

为了控制演示环境的处理时间和资源占用，当前线上版本有以下限制：

- 单个文件不超过 **2 MB**。
- 每个工作表最多 **5,000 行**。
- 支持 `.xlsx` 和 `.csv`。上传 CSV 后，先在对话中要求 SheetPilot 将它转换为 XLSX；确认并完成转换后，即可在当前任务中继续提出其他处理需求，无需自己转换或重新上传。
- 不支持带宏的工作簿、密码保护、Power Query、外部链接、复杂合并表头或多个工作簿之间的关联。
- 跨表匹配目前适合同一工作簿内、两个工作表之间的单列键精确匹配。
- 一个任务最多包含五个业务步骤。例如“清洗编号 → 汇总金额 → 按金额排序”计为三个步骤。
- 公式任务会检查公式结构，并在需要时调用线上表格计算引擎重新计算和检查错误。部分 Excel 专有功能可能不兼容，公式是否符合真实业务含义也仍需你确认。

如果上传失败，请先检查文件大小、工作表行数和文件格式。对于较大的数据，可以截取一部分样例行体验完整流程。

## 文件与隐私

- 请使用公开、合成或已经脱敏的数据体验，不要上传身份证号、联系方式、医疗记录、财务明细等敏感信息。
- SheetPilot 默认只向模型发送你的任务描述、表格结构和统计信息，不默认发送完整工作簿。
- 当某项处理确实需要发送具体异常值时，页面会单独说明并征求授权。
- 当前无需注册账号，任务访问与当前浏览器会话绑定；清除浏览器数据或更换浏览器后，可能无法继续访问原任务。
- 任务默认在闲置 7 天后清理，也可以在页面中主动删除。请及时下载结果，不要将线上服务当作文件存储空间。

## SheetPilot 的设计思路

传统表格工具往往要求用户先知道应该点击哪个功能、填写哪些参数或编写什么公式。SheetPilot 尝试把这套过程改成一次可检查的对话：

**理解文件 → 澄清规则 → 展示计划 → 用户确认 → 执行处理 → 核验结果 → 生成新版本**

操作计划和结果摘要让每一步都更容易检查；处理成功后生成新文件，便于保留原始数据并比较不同版本。

## 项目状态

SheetPilot 当前是用于产品探索和作品展示的演示版本，并非商业化在线服务。它聚焦于可描述、可确认、可核验的常见表格任务，仍在继续完善任务覆盖范围、交互体验和线上稳定性。

如果你在体验过程中发现需求被误解、规则说明不清楚或结果不符合预期，欢迎[提交 GitHub Issue](https://github.com/Hateprograming/SheetPilot/issues)，记录使用的表达方式、预期结果和实际结果。提交问题时请删除文件中的敏感信息。
